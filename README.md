## 📌 專案簡介

數位敘事力期刊是一個專注於教育科技與數位敘事的知識分享平台，由吳奇老師創辦並主編。本專案旨在建立一個現代化、視覺化、易於導覽的線上期刊網站，為教育工作者提供最新的教學工具、研究成果與實踐經驗。

### 關於期刊

- **創辦人**: 吳奇（Chi K. Wu）
- **定位**: 教育科技知識分享平台
- **使命**: 提供教師教育科技應用參考，促進教育創新與數位轉型
- **社群**:
  - Instagram: [@journal_of_digital_narrative](https://www.instagram.com/journal_of_digital_narrative/)
  - Facebook: [數位敘事力期刊](https://facebook.com/數位敘事力期刊Journal-of-Digital-Narrative)

### 核心主題

1. 🤖 **AI與教育科技** - 生成式AI、教學工具、自動化應用
2. 📱 **數位工具應用** - EdTech工具評測與使用指南
3. 📚 **華語文教學** - 數位化華語教學實踐
4. 💡 **創新教學實踐** - 教學方法與課程設計
5. 🔬 **教育研究** - 學術研究與趨勢分析
6. 🌐 **跨領域整合** - 跨學科教學應用

## 🚀 快速開始

### 前置需求

```bash
Node.js >= 18.14.1
npm >= 9.0.0（或 pnpm >= 8.0.0）
Git
```

### 技術棧（推薦）

```
核心框架: Astro 4.x
樣式框架: Tailwind CSS 3.x
動畫庫: Framer Motion / GSAP
圖標: Heroicons + Phosphor Icons
部署平台: Vercel / Netlify
```

### 安裝步驟

```bash
# 1. 複製專案
git clone https://github.com/your-username/Journal-of-Digital-Narrative-Website.git
cd Journal-of-Digital-Narrative-Website

# 2. 安裝依賴
npm install

# 3. 啟動開發伺服器
npm run dev

# 4. 建構專案
npm run build

# 5. 預覽建構結果
npm run preview
```
